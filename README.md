# ASM Music Cassette

Lecteur cassette rétro-futuriste ASM en HTML/CSS/JavaScript, optimisé pour mobile et iPhone.

## Publication avec GitHub Pages

1. Créez un dépôt GitHub.
2. Envoyez tout le contenu de ce dossier à la racine du dépôt.
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**.
4. Sélectionnez la branche **main** et le dossier **/(root)**, puis enregistrez.

La page d'accueil est `index.html`.

## Fonctions incluses

- Cassette animée et bobines en mouvement
- VU-mètres LED animés
- Commandes lecture / pause / stop
- Répétition désactivée / playlist / morceau
- Mode lecteur plein écran
- Interface responsive mobile
- Manifest PWA et icônes pour navigateur / écran d'accueil

> Les boutons de services musicaux présents dans cette version sont des éléments d'interface. Toute intégration de lecture en ligne doit utiliser les API/SDK officiels des services concernés et respecter leurs conditions d'utilisation.


## Bibliothèque interactive
- Ajout de fichiers audio locaux
- Playlist générée dynamiquement
- Lecture, pause, stop, précédent/suivant, seek et répétition
- Boutons des plateformes ouvrant leurs services web officiels
